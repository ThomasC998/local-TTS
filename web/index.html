Quick voice design — one script, several takes, keep the one you like

Each take is the same script in a different voice, generated from seed, seed+1, seed+2 and so on. Takes play automatically in order as they arrive. Saving one stores its audio as the voice's reference recording together with every setting that produced it, so the voice can speak text it has never seen and still sound like itself.
Cloning works from about 10 seconds of speech; 15 seconds or more is noticeably better. Use one speaker with no music or background noise, and pick a passage that is as varied as possible — mixed sentence lengths, a question and a statement, a real range of pitch and pace. A flat, monotone sample clones as a flat, monotone voice. There is no speech recognition here, so the transcript has to be supplied by hand and has to be exact: a wrong transcript audibly degrades the clone.

Tone rotation
A two-page article read in one unvarying tone gets tiring. Rotation swaps between the voice's reference recordings as the read goes on — same speaker, different colour. It only switches at a paragraph break, so the change is never audible mid-sentence. Add variations to a voice on the Voice library tab.
